# Personal Knowledge Management System

Sistema personal de gestión de conocimiento usando Obsidian + GitHub.

## Estructura

- **00 - Documento Maestro:** Visión general, objetivos y seguimiento
- **01 - Dirección Personal:** Decisiones y dirección de vida
- **02 - Tesis e Investigación:** Trabajo académico e investigación
- **03 - Finanzas Personales:** Gestión financiera y patrimonio
- **04 - Organización y Productividad:** Sistemas, hábitos y procesos
- **05 - Aprendizaje Técnico:** Desarrollo de habilidades técnicas
- **06 - Carrera Profesional:** Desarrollo profesional y networking
- **07 - Conversaciones Libres:** Notas, ideas y reflexiones

## Uso

Este repositorio se usa con [Obsidian](https://obsidian.md/) para navegación y vinculación de notas.
