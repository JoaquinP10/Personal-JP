# Inbox

> Punto único de captura durante el piloto semanal.

## Regla de uso

- Capturar aquí en pocos segundos.
- Escribir una sola línea suficientemente clara para reconocer el elemento después.
- No asignar prioridad, proyecto ni fecha durante la captura.
- Si una extensión del objetivo actual es trivial y evidente, puede integrarse directamente en el tablero semanal.
- Todo lo demás se procesa durante la Revisión Semanal o antes si no puede esperar.

Formato sugerido:

```text
- [ ] AAAA-MM-DD — elemento capturado
```

## Por procesar

- [ ] 2026-08-16 — Preparar el arranque de la primera semana piloto.

## Al procesar

Cada elemento debe terminar en una de estas salidas:

- descartar;
- guardar como referencia;
- integrar como objetivo de un proyecto existente;
- incorporar como cambio de Contexto;
- evaluar como posible proyecto nuevo.

Una vez integrado, se elimina de `Por procesar`. Inbox no conserva historial.
