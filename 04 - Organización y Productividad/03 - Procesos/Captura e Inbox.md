# Captura e Inbox

**Versión:** v1.0  
**Estado:** Proceso operativo

---

## 1. Propósito

Captura permite registrar rápidamente información nueva sin interrumpir el trabajo actual.

> Capturar no significa decidir.

Inbox es la cola temporal donde permanecen los elementos todavía no integrados al sistema.

---

## 2. Qué puede entrar

- ideas;
- tareas o trabajo descubierto;
- recordatorios;
- cambios relevantes;
- enlaces o información que requiere procesamiento;
- posibles proyectos.

---

## 3. Regla de captura

La captura debe tomar pocos segundos.

No se debe decidir en ese momento:

- prioridad;
- proyecto definitivo;
- planificación;
- nivel de detalle.

---

## 4. Procesamiento del Inbox

Cada elemento puede terminar como:

- descartar;
- referencia;
- objetivo de un proyecto existente;
- cambio de Contexto;
- candidato a nuevo proyecto mediante Evaluación Estratégica.

Procesar significa integrar el elemento al modelo operativo, no solo moverlo de lista.

---

## 5. Trabajo nuevo durante ejecución

Ruta normal:

```text
Trabajo nuevo
→ Inbox
→ procesamiento
→ proyecto / objetivo / estado
```

Excepción:

Una extensión trivial y evidente del objetivo actual puede integrarse directamente.

---

## 6. Frecuencia

El procesamiento normal ocurre durante la Revisión Semanal.

Si el elemento es importante y no puede esperar:

- procesarlo ASAP;
- replanificar si solo afecta el plan;
- reevaluar Activación si afecta compromisos o capacidad global.
